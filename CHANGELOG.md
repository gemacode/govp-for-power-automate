# Changelog

## 0.1.1 — 2026-08-16

- ciclo nativo completo validado en Power Automate: conexión, identidad,
  emisión, replay idempotente, comprobación y revocación;
- alias autenticado de comprobación para conservar la conexión de Azure API Hub;
- emisión y revocación aceptadas desde Power Automate con credencial de conector;
- esquema de revocación compatible con el validador del runtime nativo.

## 0.1.0 — 2026-08-16

- custom connector OpenAPI 2.0;
- acciones de identidad, emisión, comprobación y revocación;
- credencial segura e idempotencia obligatoria;
- triggers reservados hasta disponer de webhooks firmados.
